# Assignment 4 — Forms and Validation

Student: Daniyal Akylbek  
Group: SE-2530

## Run

Extract the ZIP and open index.html in a browser. Bootstrap 5.3.8 CSS is included locally, so the pages also work offline. No installation is needed.

## Pages

- index.html (Tasks 0 and 1 together): basic contact form with labels, name, email, message and submit button; HTML5 validation using required, type=email and maxlength.
- task2.html: Bootstrap form-control, form-label, form-text, buttons and responsive grid.
- task3.html: interactive Bootstrap CSS feedback and separate static is-valid / is-invalid examples.
- task4.html: responsive registration form, names, email, password fields, radio buttons, checkboxes, select, submit and reset.
- success.html: destination for this static demonstration
